# GarrysModMods

**В планах.** Набор аддонов для Garry's Mod: физические игрушки, катастрофы, машинка, которая учится ездить, и
игровой автомат с настоящими мини-играми внутри. Все аддоны работают в мультиплеере.

## Какие будут аддоны

| Аддон | Что делает |
|---|---|
| Чёрный ящик | Записывает, что происходило вокруг, и показывает повтор с любой камеры. |
| Катастрофы | Землетрясение, торнадо и цунами, которые по-настоящему ломают и уносят предметы. |
| Катапульта и FPV-дрон | Собрать катапульту и запускать предметы; летать на дроне от первого лица. |
| Машинка, которая учится | Маленькая машинка сама учится проходить трассу, а ты смотришь, как она становится лучше. |
| Игровой автомат | Автомат с мини-играми на экране (из ИИ-Игротеки автора); некоторые игры можно «вынуть» в 3D прямо на карту. |
| Мини-Paint | Рисовать на любой поверхности кистью, фигурами и цветами. |
| Резак | Разрезать предметы на части по выбранной линии. |
| Уменьшитель и увеличитель | Сделать игроков и предметы крошечными или огромными. |
| 3D-принтер | Принтер, который «печатает» модель слой за слоем. |
| Чёрная дыра | Затягивает всё вокруг, с растущей силой. |

## Как будет устроено

- Lua-аддоны Garry's Mod, у каждого своя папка, общий код в общей библиотеке.
- Мультиплеер с самого начала: состояние игры держит сервер, клиенты только рисуют.
- Перед каждым аддоном - проверка Мастерской на похожие, чтобы он давал что-то новое.
- Выкладка: Мастерская Steam (gmad и gmpublish) и этот репозиторий.
